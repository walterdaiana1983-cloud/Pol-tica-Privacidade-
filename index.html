Política de Privacidade — Meu Controle Financeiro Premium

Última atualização: 2 de novembro de 2026.

1. Dados armazenados

Os registros financeiros, metas e movimentações inseridos pelo usuário ficam armazenados localmente no dispositivo.

2. Compartilhamento

O aplicativo não envia esses registros financeiros para servidores próprios nem os compartilha com terceiros.

3. Internet

O aplicativo pode utilizar recursos externos, mas os registros financeiros permanecem armazenados localmente.

4. Exclusão dos dados

O usuário pode apagar os dados nas configurações do dispositivo. A desinstalação ou limpeza dos dados do aplicativo também pode remover essas informações.

5. Recursos Premium

Na versão atual, o desbloqueio Premium depende de confirmação manual e não possui validação automática de pagamentos.

6. Segurança

Recomendamos proteger o dispositivo e manter cópias de segurança dos dados importantes.

7. Contato

Para dúvidas sobre esta política, procure o responsável pelo aplicativo.
